🍽️ Restaurants & Food

  • Çiya Sofrası (Kadiköy) — Renowned for traditional Anatolian dishes. The host recommends the lamb tandir and stuffed grape leaves.
  • Karaköy Lokantası — Upscale Turkish comfort food with harbor views. Grilled octopus highlighted as a must-try.
  • Balıkçı Sabahattin — Fresh fish restaurant near Sultanahmet. Family-run for 90+ years.

📍 Activities & Sights

  • Balat neighborhood — Colorful streets, antique shops, and the Iron Church. Best visited in morning for photographs.
  • Princes' Islands ferry — 1.5 hour ride from Kadiköy, horse-drawn carriages now replaced by electric vehicles.
  • Grand Bazaar back streets — Lesser-known artisan workshops behind the main corridors.

💡 Tips

  • Use Istanbulkart for all public transport — much cheaper than tokens.
  • Avoid taxis from Sultanahmet; use metro + tram instead.

SwiftUI Architecture Notes

Navigation

  • NavigationSplitView with sidebar + detail
  • Sidebar uses List with NavigationLink
  • SF Symbols replace emoji in production
  • Supports both macOS sidebar and iOS tab bar

Data Flow

  • @Observable view models per feature
  • SwiftData for profile + history persistence
  • Existing Python backend via embedded server or Swift rewrite
  • Async/await for all API calls with progress

Key Views

  • HomeView — quick actions + recent activity
  • SummarizerView — URL input, step progress, result tabs
  • RecommendView — filters, map, scored place cards
  • PlannerView — config form, day-by-day timeline
  • ProfileView — preferences, liked places, history
  • SettingsView — API keys, toggles, cache management

Platform Integration

  • MapKit for native map with place pins
  • Keychain Services for secure API key storage
  • NLLanguageRecognizer for language detection
  • Universal app: macOS + iOS with adaptive layout
